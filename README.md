# Skyfall

**Play: https://playskyfall.github.io/**

A first-person anti-air wave shooter. Hold the FOB against helicopters, jets, bombers and drone swarms. Build HESCO walls and turrets, hire a squad, upgrade your weapons to Mk II, and pull the lever when you're ready for the next wave.

Runs in any modern desktop browser (Chrome, Edge, Firefox). Use headphones for the full sound.

Main-menu music: *Taps*, played by a member of the United States Army Band (public domain).

This repository holds only the built game, published automatically from the private development repository.
